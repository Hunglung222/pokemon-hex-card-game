# ⬡ 寶可夢六角蜂巢卡牌遊戲

獨立可玩版本（從《寶可夢學習宇宙》拆分出來）

## 功能

1. **自由對戰** — 選卡 → 六角棋盤對戰（支援 SAME / PLUS 規則）
2. **闖關塔** — 完整 30 關（規則啟蒙 → 策略養成 → 大師考驗），含新手卡包、獎勵、星等
3. **鍛造工坊** — 把圖鑑寶可夢鍛造成六角卡 + 強化六邊數值 + 回收

## 怎麼玩（最快方式）

### 方法一：開 GitHub Pages（推薦）
1. 打開本 repo → 點 **Settings**
2. 左側選 **Pages**
3. Source 選 **Deploy from a branch** → Branch 選 `main` → `/ (root)` → Save
4. 等約 1 分鐘，網址會出現：
   **https://hunglung222.github.io/pokemon-hex-card-game/**

### 方法二：本機直接開
把整個專案下載後，用瀏覽器打開 `index.html` 即可（建議用 Live Server）。

## 注意
- 目前為獨立可玩版本，戰鬥邏輯是簡化但完整可玩的版本（支援翻牌、SAME、PLUS、AI、闖關塔整合）。
- 所有進度與卡牌存在瀏覽器 localStorage。
- 原始《寶可夢學習宇宙》完全沒有被修改。
